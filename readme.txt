== Description ==

**WPCalibrate Robots Repair** is a professional crawl diagnostic and repair engine for WordPress. It is far more than a text editor: it scans your live public `/robots.txt` endpoint, pinpoints crawl-control errors, explains the search engine impact in plain English, applies safe minimal repairs with automated backups, and verifies the public HTTP result after changes.

### The Problem With Ordinary robots.txt Editors
Most plugins simply give you a blank textarea. If you make a mistake—such as accidentally leaving `Disallow: /` active or blocking your theme's JavaScript and CSS—ordinary editors say "Saved Successfully," while search engines silently drop your site from search results.

WPCalibrate solves this through an end-to-end reliability workflow:
**Scan → Diagnose → Explain → Repair → Verify**

### Key Features
* **Public Network Diagnostics**: Requests your canonical `/robots.txt` to inspect real-world HTTP status, response headers, CDN/WAF layers, and HTML error pages.
* **RFC 9309 Compliant Rule Parser**: Accurately tracks User-agent groups, comments, directive casing, and unknown directives without destroying custom formatting.
* **3-State Severity Model**: Categorizes findings into Healthy, Warning, and Critical with plain-language explanations and evidence.
* **Source Attribution**: Detects whether your live output is generated by a physical file on disk, WordPress virtual rules, WPCalibrate, or third-party SEO plugins.
* **Dangerous Rule Prevention**: Detects accidental site-wide blocks (`Disallow: /`) and warns you that robots.txt controls crawler access, not page deindexing.
* **Resource Blocking Defense**: Alerts you if CSS, JavaScript, themes, or uploads are blocked, ensuring Googlebot can render your layout properly.
* **Sitemap Accessibility Verification**: Live HTTP testing of declared and auto-detected sitemaps to verify they return HTTP 200 OK.
* **Search Engine Visibility Inspection**: Detects mismatches between your WordPress Reading settings (`blog_public`) and actual robots.txt rules.
* **Automated Bounded Backups**: Safely creates an atomic backup before every write or preset reset.
* **Mandatory Post-Repair Verification**: Immediately requests the live public URL after repairs to confirm the change took effect. Detects CDN and proxy cache lag.
* **Optional WooCommerce Integration**: Generates justified crawl restrictions for dynamic cart, checkout, and account endpoints without blocking products or categories. Does not touch orders, sessions, or HPOS storage.
* **Defensive Admin Menu Architecture**: Coexists seamlessly alongside other WPCalibrate plugins without duplicate menus or contaminated links.
* **Lightweight & High Security**: Enforces strict SSRF protections, path-traversal defenses, capability checks (`manage_options`), nonces, and zero frontend performance overhead.

== Installation ==

1. Upload the `wpcalibrate-robots-repair` folder to the `/wp-content/plugins/` directory, or install the ZIP directly via **Plugins → Add New → Upload Plugin**.
2. Activate the plugin through the **Plugins** screen in WordPress.
3. Navigate to **WPCalibrate → Robots Repair** in your admin menu.
4. Click **Scan Robots.txt** to inspect your site's current crawl health.

== Frequently Asked Questions ==

= Does robots.txt guarantee that pages will be removed from Google? =
No. robots.txt instructs search engines whether they may crawl a URL. It does not remove pages from search indexes. If an external site links to a blocked URL, search engines can still index the URL as an empty link snippet. To prevent indexing, use a `<meta name="robots" content="noindex">` tag or require user authentication.

= What is the difference between physical and virtual robots.txt? =
If a physical `robots.txt` file exists in your website's root directory, your web server (Apache, Nginx, LiteSpeed, etc.) serves that static file directly, bypassing WordPress. If no physical file exists, WordPress dynamically serves a virtual robots.txt via rewrite rules. WPCalibrate detects both and safely manages either.

= Does this plugin require WooCommerce? =
No. WooCommerce is entirely optional. When WooCommerce is active, an optimized WooCommerce Store preset becomes available.

= Will this plugin modify my database or WooCommerce orders? =
No. This plugin never touches products, orders, customers, or checkout rendering blocks. It only inspects public URL permalinks.

= How do backups work? =
Before any write operation (preset reset, automatic repair, or manual save), WPCalibrate creates a timestamped, hashed backup. You can restore any previous version with a single click from the Backups tab.
